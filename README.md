# 🎯 JobRadar

**Track your job applications with a sleek, minimalist interface.**

JobRadar is a **React-based** job application tracker with **glassmorphism UI, animations, and radar-inspired design**. Built with **Tailwind CSS, Framer Motion, and localStorage** for persistence.

## ✨ Features
✅ **Add, edit, delete** job applications
✅ **Filter & sort** by status, date, or company
✅ **Dark/light mode** toggle
✅ **Persistent data** with localStorage
✅ **Analytics dashboard** (status distribution)
✅ **Smooth animations** (Framer Motion)
✅ **Responsive design** (mobile-friendly)
✅ **Custom favicon & branding**

## 🛠 Tech Stack
- **Frontend**: React, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Feather
- **Data**: localStorage
- **Charts**: Chart.js
